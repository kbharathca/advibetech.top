## 🚀 Key Features
* **Direct-to-Owner WhatsApp Booking Form**: Captures candidate name, contact number, village/mandal/district, election symbol, party colors, quantities, and sends an engineered, pre-formatted order payload straight to owner Sura Devi Prasad (+91 7075209795).
* **Haptic Touch Physics**: Native micro-vibrations on mobile taps for a responsive app feel (`hooks/useHaptic.ts`).
* **Live Candidate Mockup Studio**: Real-time interactive SVG generator for candidate keychains and mobile stickers with live name and symbol updates.
* **Bilingual English & Telugu Toggle**: Instant zero-reload switch between Telugu and English.
* **Sarpanch Victory Kits**: Curated combo bundles (Starter & Mega packages) for village-level campaigns.
* **Real Production Walkthrough**: Embedded mobile reel player with sound and fullscreen toggles.
* **PWA & Mobile-First**: Installable to Android/iOS home screens with persistent bottom navigation dock.
